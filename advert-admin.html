Advert management

This page is a shortcut to the central advert inventory. Publishing rights are controlled by GitHub repository access. Only an account with write permission to the Vijes website repository can change the live advert inventory.

Before publishing an advert

  1. Review the advertiser and the submitted creative.
  2. Send a written quotation and agree the placement and campaign dates.
  3. Verify payment in the payment provider account. Do not rely on screenshots or receipts supplied by the advertiser.
  4. Only then add the approved advert to the inventory and set its status to published.
  5. Set accurate start and end dates. The website automatically hides adverts outside their campaign dates.
  6. When a campaign ends or is paused, change its status to paused or remove it.

Manage the live inventory

Use the secure GitHub editor. GitHub will require you to sign in and will only allow authorised repository collaborators to save changes.

Advert record format

The inventory starts empty. Add an item inside the ads array using this structure, replacing the example values with the advertiser's approved information:

{
  "id": "unique-campaign-id",
  "advertiser": "Approved business name",
  "headline": "Advert headline",
  "description": "Short accurate advert description",
  "imageUrl": "https://example.com/advert-image.jpg",
  "imageAlt": "Description of the advert image",
  "destinationUrl": "https://example.com",
  "callToAction": "Visit website",
  "placement": "featured",
  "startDate": "2026-11-20",
  "endDate": "2026-12-20",
  "status": "published",
  "approved": true
}

Important: never publish an advert before payment has been independently verified and the content approved. Do not add customer contact details, payment records or private documents to this public file. The advert inventory is public website content.
